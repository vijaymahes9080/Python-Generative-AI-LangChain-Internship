System & Security Architecture

Engineered for fault-tolerance, zero-trust execution, and reproducible testing.

🛡️ Zero-Trust Tooling
The calculator parses Python's Abstract Syntax Tree (AST) directly; eval() and exec() are completely omitted. The file reader enforces canonical path containment, blocking any traversal outside the sandbox.
⚡ Dual-Mode Engine
All four tasks support live LLM providers (Google Gemini & OpenAI) alongside internal deterministic engines. Tests and local review run 100% offline without requiring external API keys.
🔒 Grounded Citations
The RAG engine calculates cosine similarities and enforces strict refusal when queries lack documentary evidence. Unsupported statements are never manufactured or hallucinated.
🔄 Bounded Self-Correction
When unstructured inputs produce malformed JSON or schema mismatches, Pydantic v2 diagnostics are fed back into the extraction loop (max 2 retries) to self-repair records cleanly.
